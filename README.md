# ⚡ Hybrid EVM Blockchain Project

Welcome to the **Hybrid EVM Blockchain Project** — a cutting-edge blockchain architecture combining the flexibility of Ethereum Virtual Machine (EVM) with advanced scalability, security, and modular design. Built with passion by [Wawan Insanudin](https://github.com/cebonganyut).

---

## 🚀 Overview

This project is a hybrid blockchain platform designed to support smart contracts, DApps, and seamless integration with existing Ethereum tools. It’s built using Hardhat, a React frontend, and modular contract structure for extensibility.

---

## 🛠 Tech Stack

- **Blockchain Framework**: Hardhat + Solidity
- **Smart Contracts**: Ethereum-compatible (EVM)
- **Frontend**: React.js
- **Testing**: Hardhat + Mocha/Chai
- **Other Tools**: dotenv, ethers.js, web3
